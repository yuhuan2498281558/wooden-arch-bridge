# 五节苗八点标注工具

该页面用于在木拱桥纵剖面图或立面图上标注：

- 三节苗锚点 `A、B、C、D`；
- 五节苗牛头节点 `Q1、Q2、Q3、Q4`。

页面在浏览器本地读取图像，不向服务端上传原图。完成八点后自动计算：

- `alpha_left`、`alpha_right`：以三节苗斜弦为固定方向、沿桥轴分解得到的外侧节点比例；
- `beta_left`、`beta_right`：内侧节点从左右三节苗牛头向跨中的投影比例；
- 左右平均的 `alpha`、`beta`；
- 对称误差、五节苗虚拟起点抬高量和点到三节苗轴线的归一化偏差。

## 启动

启动桥梁算法服务：

```powershell
.\start_bridge_algorithm.ps1
```

打开：

- 本机开发：`http://127.0.0.1:8001/annotation`
- Docker 部署：`http://<host>:6000/bridge-api/annotation`

## 使用顺序

1. 点击“选择图纸文件夹（最新优先）”并选择纵剖面图目录，再从页面内按文件时间从新到旧的列表选择图纸；浏览器不支持目录读取时可用“单独选择图纸”；
2. 依次点击 `A、B、C、D、Q1、Q2、Q3、Q4`；
3. 检查比例范围、对称误差和轴线偏差提示；
4. 填写桥梁 ID、桥名、总跨数、当前跨序号、当前跨净跨、图纸来源、标注者和质量等级；
5. 点击“选择导出文件夹”，创建或选择专用目录（建议命名为 `five_miao_annotations`）；
6. 导出 JSON 作为可恢复的标注记录，导出 CSV 作为单行训练数据；
7. 双人标注时分别保存文件，不要互相覆盖，之后再进行裁决合并。

## 画布操作

- 节点字母默认隐藏，避免遮挡图纸节点；点击“显示字母”或按 `L` 临时显示，当前正在复核的点仍会自动隐藏字母；
- 点击“拖动：关”切换为拖动画布模式，或按住空格后用左键拖动；鼠标中键可随时拖动；
- 按住 `Ctrl`（macOS 为 `Command`）滚动鼠标滚轮，以指针所在位置为中心缩放；普通滚轮仍用于滚动画布；
- 点击左侧某个已标点后，可在图上重新点击位置进行修正；数字键 `1` 到 `8` 可快速选择对应点；
- “适合窗口”恢复整图视图，“1:1”恢复原始像素比例。

复核已有记录时应先载入 JSON，再选择该 JSON 的 `source_image.file_name` 对应原图；页面会保留八点并显示“原图已匹配”。选择其他新图时仍会清空八点并开始新的记录。

图纸文件夹列表使用浏览器能够读取的 `lastModified` 文件时间降序排列，同一时间再按文件名降序排列。系统“打开文件”窗口的排序由 Windows 单独管理，网页无法强制修改，因此建议日常标注使用页面内的文件夹列表；选择文件夹时不会上传、移动或改名其中的图纸。

批量复核时点击“选择待复核 JSON（可多选）”建立队列。页面显示当前序号和文件名；为当前记录选择对应原图、调整并导出后，再点击“下一条”。如果下一条使用另一张原图，上一张图会自动隐藏，避免把旧底图误用于新记录；同一张多跨图的连续记录则可继续复用已经匹配的底图。

多跨桥采用“一跨一条标注记录”，不要把整座桥的总长当成当前跨净跨。保持同一桥梁 ID 和总跨数不变，从左到右依次标注；导出文件自动带有 `_span_01_of_03` 形式的跨序号。点击“下一跨”只保留桥梁级信息并清空八点，切换前应先导出当前跨。若各跨净跨不同，每次切换后需要重新填写当前跨净跨。

原址/迁建、毁损/重建，或多个桥名实际共享同一测绘来源时，应填写相同的“谱系分组 ID”。训练和评估按该分组隔离，同一座桥的各跨不会被拆到训练集和测试集两边。

选择原图或载入已有 JSON 时，如果其中仍是 `DEMO / 比例计算演示` 或桥名为空，页面会使用原图文件名作为桥名，并据此区分后续导出的 JSON、CSV 文件；有效的桥梁 ID 和桥名仍优先保留。

指定文件夹后，本次页面会话中的 JSON、CSV 均直接写入该目录；同名文件会自动增加 `(2)`、`(3)` 后缀，不覆盖旧标注。浏览器首次选择目录时需要用户确认权限；若浏览器不支持目录选择，则回退到默认下载目录。

首次使用可点击“载入演示图”和“填入演示八点”，核对工具能否得到 `alpha≈2/3`、`beta≈1/4`。演示记录不得混入研究数据。

## 数据约束

- `0 < alpha < 1`
- `0 < beta < 0.5`
- 第一版按构件中心轴线取点并忽略厚度；
- 外斜弦角度固定为对应三节苗斜弦角度；厚度造成的起点抬高按桥轴法向分离，不得混入 `alpha`；
- 原始像素坐标必须保留，不要只保存平均比例；
- 当前跨净跨以米为单位保存为 `span.clear_span_m`，并兼容写入 `bridge.span_m`；`span.index`、`span.count` 分别表示从左到右的跨序号和总跨数；
- 每个 JSON 只对应一跨。节点位置仍使用无量纲比例，绝对坐标由该跨的设计坐标系恢复；
- 网站图纸必须在授权范围内使用，工具本身不代表已获得图纸使用许可。
