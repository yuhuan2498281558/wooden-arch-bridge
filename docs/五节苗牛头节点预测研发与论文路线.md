# 五节苗牛头节点位置预测：数据集、算法、系统集成与论文路线

> 版本：v1.1（2026-08-11，根据四节点示意图修订）  
> 适用项目：木拱桥智能设计系统  
> 目标：利用现存木拱桥测绘资料预测五节苗左右各两个、共四个牛头节点的位置，并将结果稳定地接入当前设计与绘图流程。

## 1. 结论先行

本问题不宜直接做成“从桥梁图片端到端识别四个点”的深度学习任务。根据项目负责人提供的标注示意图，忽略构件厚度后，四个五节苗牛头节点分别位于三节苗的左右斜杆和中间平杆轴线上，并按桥跨中心对称。三节苗几何可以先行得到，因此四点位置可压缩为两个无量纲比例：外侧斜杆比例 `alpha` 和内侧平杆比例 `beta`。建议采用以下主路线：

1. 将四个牛头节点标为外左、内左、内右、外右，并从图纸计算 `alpha`、`beta`；
2. 从历史桥梁数据库建立“桥梁级元数据 + 测绘图 + 人工关键点标注”的小样本数据集；
3. 以当前 `alpha=2/3`、`beta=1/4` 固定比例作为基线；先判断比例是否确实随桥梁参数变化，再决定采用统计常数还是知识约束残差模型；
4. 通过对称性、边界、杆件归属和可构造性约束保证输出不会生成错误拓扑；
5. 模型同时返回不确定性和越界判定，低置信度时回退到规则值并要求人工确认；
6. 在系统中保留节点拖拽修正入口，把后续修正沉淀为增量数据，但不得混入已锁定测试集；
7. 论文围绕“小样本、知识约束、相对固定比例规则的改进、系统下游收益”展开，而不是仅报告一个较高的拟合指标。

截至 2026-08-11 对公开接口的快照统计，网站约有 250 座桥，其中木拱桥约 132 座；带测绘图的木拱桥约 115 座；关键词为“3+5”且有测绘图的候选桥约 99 座。该数量足以开展规范的小样本回归和交叉验证，但不足以支撑高参数量的通用视觉网络。最终有效样本还会因图纸视图、清晰度、节点可辨识性和授权情况继续减少。

## 2. 当前系统诊断

### 2.1 原开发方案的边界

原开发方案借鉴论文《数据-知识混合驱动的木拱桥设计参数两阶段预测模型》，计划使用：

- 第一阶段：SSA-XGBoost 预测矢跨比；
- 第二阶段：带知识约束的 CF-BPNN 预测五类构件直径范围；
- 输入包括桥长、桥宽、净跨、三节苗/五节苗数量、跨数等总体参数。

这套思路解决的是总体设计参数和构件尺寸问题，没有定义或预测五节苗牛头节点几何位置。因此，节点预测应作为独立的“几何补全阶段”加入，而不应强行塞进原有直径预测输出中。

论文信息：王黎园、姜绍飞、王威、陈宇涵、夏樟华、邱楚怡，《数据-知识混合驱动的木拱桥设计参数两阶段预测模型》，《应用基础与工程科学学报》2025 年第 33 卷第 6 期，1582–1593，DOI：[10.16058/j.issn.1005-0930.2025.06.003](https://doi.org/10.16058/j.issn.1005-0930.2025.06.003)。

### 2.2 规划阶段代码中的直接原因

规划阶段的 `bridge_algorithm_service/main.py` 中，桥梁参数预测是本地规则估计器，未加载 SSA-XGBoost 或 CF-BPNN；绘图函数对关键节点采用固定几何规则：

- 三节苗左右牛头横坐标固定在跨径的 `1/3` 和 `2/3`；
- 五节苗外侧左右牛头固定在左、右斜杆的 `alpha = 2/3` 处，折算为跨径归一化横坐标约为 `2/9` 和 `7/9`；
- 五节苗内侧左右牛头固定在三节苗平杆两端向内的 `beta = 1/4` 处；
- 五节苗相对三节苗的“厚度”使用固定 `12 px` 竖向偏移。

原算法没有给四个节点施加学习得到的位置约束，所以代码用 `2/3` 和 `1/4` 作了临时假定。第一版研究暂不预测厚度，但预处理必须先分离厚度造成的法向抬高量，设计重建时令外斜弦角度与对应三节苗斜弦一致；待比例预测验证后，再由构件直径或专家规则确定法向偏移。当前工程缺口因此可以精确表述为：系统没有经过平行角度修正的 `alpha`、`beta` 标签和预测器。

### 2.3 推荐的新流水线

```text
总体设计输入
    ↓
原两阶段参数预测（矢跨比 / 构件直径）
    ↓
节点几何特征构造（全部无量纲化）
    ↓
五节苗比例预测 alpha、beta（统计检验 → 规则或约束残差模型）
    ↓
可行域投影、置信区间与 OOD 判定
    ↓
参数化绘图 / 人工拖拽修正 / 结果留痕
```

## 3. 四节点的正式参数化

### 3.1 节点和三节苗锚点

根据 2026-08-11 提供的圈点示意图，沿桥跨从左到右定义四个五节苗牛头节点：

- `Q1`：外左节点，位于三节苗左斜杆；
- `Q2`：内左节点，位于三节苗中间平杆；
- `Q3`：内右节点，位于三节苗中间平杆；
- `Q4`：外右节点，位于三节苗右斜杆。

再定义已经能够由三节苗预测结果得到的四个锚点：

- `A`：左拱脚；
- `B`：三节苗左牛头；
- `C`：三节苗右牛头；
- `D`：右拱脚。

原始标注按图纸中的构件中心位置取点；系统设计按桥跨中心对称。由于木材厚度会使五节苗外斜弦的起点相对三节苗拱脚抬高，预处理不能把 `A—Q1`、`D—Q4` 的视线角当作五节苗斜弦角，而应固定五节苗斜弦与对应三节苗斜弦平行，并将起点抬高量作为独立法向偏移保存。

### 3.2 两个学习目标

四个二维节点不需要分别学习。先以 `B—C` 定义桥轴单位向量 `u`，以 `n` 表示桥轴向上的法向单位向量，再对每张图计算：

```text
alpha_L = dot(Q1 - A, u) / dot(B - A, u)
alpha_R = dot(Q4 - D, u) / dot(C - D, u)

h_L = dot(Q1 - A - alpha_L × (B - A), n)
h_R = dot(Q4 - D - alpha_R × (C - D), n)

beta_L  = dot(Q2 - B, C - B) / ||C - B||²
beta_R  = dot(Q3 - C, B - C) / ||B - C||²

alpha = (alpha_L + alpha_R) / 2
beta  = (beta_L  + beta_R)  / 2
```

其中：

- `alpha` 表示外侧牛头从拱脚沿三节苗斜杆向三节苗牛头移动的比例，满足 `0 < alpha < 1`；
- `h_L、h_R` 表示木材厚度、构件间距和测绘误差共同形成的五节苗起点法向抬高量，第一版以跨长归一化后用于质控和分层分析，不作为节点比例预测目标；
- `beta` 表示内侧牛头从三节苗牛头沿中间平杆向跨中移动的比例，满足 `0 < beta < 0.5`；
- 当前代码的临时假定值是 `alpha_0 = 2/3`、`beta_0 = 1/4`；
- `|alpha_L-alpha_R|` 和 `|beta_L-beta_R|` 作为历史结构不对称诊断指标，第一版生产模型不预测它们，也不因其数值较大而自动判定标注错误或排除样本。

这种桥轴分解比例对图像平移、旋转和统一缩放不敏感，同时不会把厚度造成的平行错位混入 `alpha`。只要技术图纸中的锚点和节点能被可靠识别，就不必先从图纸恢复绝对米制坐标，特别适合当前网站的位图图纸。

智能设计中的三节苗采用三等分投影约束：左斜弦的水平投影、`B—C` 平弦、右斜弦的水平投影各为净跨 `L/3`。因此三节苗设计斜弦角满足 `theta=atan(3f/L)`。矢跨比 `f/L` 与斜弦角是同一几何信息的确定性表达，特征建模时二选一；绝对矢高 `f=L×(f/L)` 可作为跨度与矢跨比的显式交互候选，但是否保留必须由分组消融实验决定。

### 3.3 从比例恢复四点

三节苗几何 `A、B、C、D` 已知后，四点直接恢复为：

```text
Q1 = A + alpha × (B - A)
Q2 = B + beta  × (C - B)
Q3 = C + beta  × (B - C)
Q4 = D + alpha × (C - D)
```

因此模型只输出 `(alpha, beta)`，绘图层负责转换成四个节点坐标。这比直接预测八个像素坐标更符合结构知识，也消除了当前固定 `12 px` 厚度对位置学习的干扰。

### 3.4 现状值与设计值

历史桥存在变形、维修和测量误差。数据仍应同时保留：

- `observed_left/right`：图纸左右两侧直接量出的四点及比例；
- `symmetric_target`：左右平均得到的 `alpha, beta`，作为第一版学习目标；
- `reviewed_design`：专家复核后可作为新桥设计范例的比例；
- `exclude_reason`：变形、维修改造、视图不适用、标注歧义等排除原因。

预处理阶段已经保存法向偏移 `h_L、h_R`，并以跨长归一化；第一版模型只学习平行角度修正后的 `alpha、beta`。若后续正式考虑构件厚度，再由构件直径、节点叠放规则或专家审定值生成设计法向偏移，而不是直接照搬历史桥的变形量。

左右不对称本身不构成 `exclude_reason`。只要八点按图纸真实节点标注、比例仍在几何可行域内且图纸可辨识，该样本就通过左右均值完成对称化并进入训练；原始左右值与不对称度继续保留，用于论文中的历史结构偏差分析。

另有一种拓扑不同的特殊构造：`Q2—Q3` 平弦长度为零，两根内斜弦在跨中直接相接。该记录不是标注错误，原始八点仍应保存，但不属于当前“含中部平弦的标准五节苗”预测范围。预处理以 `Q2—Q3` 沿 `B—C` 的投影长度除以 `|B—C|` 得到归一化平弦长度；考虑像素点选误差，暂以不超过 `0.01` 判为零平弦，并记录 `exclude_reason=zero_inner_flat_chord`。该阈值应随双人复标误差重新校准，特殊构造若积累出足够样本，后续应先做桥型分类，再分别建模。

## 4. 网站数据获取与合规路线

### 4.1 可用来源

历史桥梁数据库是单页应用，但存在可读取的第一方公开接口：

- 网站示例：[惠风桥详情页](http://w-bridge.wiki/#/detail/79)
- 使用与版权说明：[关于网站](http://w-bridge.wiki/#/about)
- 桥梁列表：[bridge/list](https://aujrht7gmph6dk84wqh975zv.z7.web.core.windows.net/api/bridge/list)
- 惠风桥结构化详情：[bridge/79/detail](https://aujrht7gmph6dk84wqh975zv.z7.web.core.windows.net/api/bridge/79/detail)

详情接口提供基础字段、说明文字、照片和测绘图链接。以惠风桥为例，详情说明其整体点云来自三维扫描，内部节点构造来自手工测绘；测绘图包含纵剖面图、横剖面图、拱架俯视图、平面示意图和立面图。因此，网站适合提供图纸来源和桥梁元数据，但不会直接给出可训练的牛头节点坐标。

### 4.2 授权是第 0 阶段门槛

“接口可以访问”不等于“允许批量训练、复制或公开发布”。网站“关于”页声明内容和图像版权归原作者；不超过 10 张照片或图纸时按 CC BY-NC-ND 4.0、署名且限非商业使用，超过该数量或商业使用需联系授权，正式学术出版还要求提前通知原作者。约 99 组候选图纸显然超过数量限制，而且裁切、标点、派生坐标和发布模型可能涉及“禁止演绎”的边界。因此在批量下载和标注前应取得权利人的书面许可，至少明确：

- 是否允许批量下载用于科研；
- 是否允许用图纸训练模型；
- 论文中可否展示原图或局部截图；
- 能否公开原图、派生坐标、特征表和训练代码；
- 署名方式和引用方式；
- 是否涉及不宜公开的测绘或文保信息。

若仅获内部科研许可，发布数据集时只发布记录 ID、原始 URL、哈希、派生的无量纲坐标和数据字典，不重新分发原图。

### 4.3 采集程序要求

采集程序应调用接口，不依赖网页 DOM，并满足：

1. 先保存一次列表快照，形成候选桥 ID 白名单；
2. 逐桥调用详情接口，缓存原始 JSON，不重复请求；
3. 解析图纸标题，优先保留纵剖面图、立面图和明确显示拱架节点的图；
4. 每个文件记录下载时间、来源 URL、HTTP 元数据和 SHA-256；
5. 设置低并发、限速、指数退避和可恢复断点；
6. 原始层只追加不覆盖，清洗和标注使用版本化派生层；
7. 每次发布数据版本都冻结 `manifest`，避免网站后续变化破坏复现。

## 5. 数据集设计

### 5.1 数据实体

建议把数据拆成五张表，避免一张宽表反复复制信息。

#### `bridges`

| 字段 | 说明 |
|---|---|
| `bridge_id` | 网站稳定 ID |
| `source_group_id` | 原址/迁建、毁损/重建、多跨或同一测绘来源的谱系分组 |
| `name` | 桥名 |
| `source_url` | 详情页或详情接口 |
| `region`, `year` | 仅作分层和误差分析，未经论证不作为生产特征 |
| `total_length_m` | 总长 |
| `clear_span_m` | 单跨桥目标净跨；多跨桥改存于 `bridge_spans` |
| `rise_m` | 矢高 |
| `width_m` | 桥宽；可能需要从说明文字/图纸提取 |
| `n_three`, `n_five` | 三节苗、五节苗榀数或方案定义中的相应数量 |
| `span_count` | 跨数 |
| `source_quality` | 元数据完整度 |
| `design_suitability` | 是否适合作为设计样本 |
| `exclusion_reason` | 排除原因 |

#### `bridge_spans`

| 字段 | 说明 |
|---|---|
| `bridge_id` | 所属桥，同一多跨桥各跨保持一致 |
| `span_index` | 从左到右的跨序号，从 1 开始 |
| `span_count` | 全桥总跨数，用于一致性校验 |
| `clear_span_m` | 当前跨净跨，不得用全桥总长代替 |
| `span_position_normalized` | 跨位归一化位置，单跨取 0.5，多跨取 `(index-1)/(count-1)` |
| `is_edge_span` | 是否为边跨 |
| `sample_key` | 例如 `bridge-79:span-02-of-03`，跨级样本唯一键 |

#### `drawings`

| 字段 | 说明 |
|---|---|
| `drawing_id` | 图纸唯一 ID |
| `bridge_id` | 所属桥 |
| `view_type` | 纵剖面、立面、横剖面等 |
| `url`, `sha256` | 来源和内容指纹 |
| `width_px`, `height_px` | 图像尺寸 |
| `scale_type` | 标尺、尺寸标注、未知 |
| `legibility` | 清晰度等级 |
| `eligible_for_label` | 是否可标关键点 |

#### `node_annotations`

每张可用立面/纵剖面图至少标注：

- 四个三节苗锚点 `A、B、C、D`；
- 四个五节苗牛头节点 `Q1、Q2、Q3、Q4`；
- 自动计算的 `alpha_L、alpha_R、beta_L、beta_R`；
- 左右平均目标 `alpha、beta` 和两个对称误差；
- `Q2—Q3` 的归一化平弦长度及是否属于零平弦特殊构造；
- 若需要把误差换算成米/厘米，再标图纸比例尺或可靠尺寸线；
- 标注者、标注时间、节点定义版本、置信等级和备注。

同时保存八个点的原始像素坐标和计算后的比例，不要只保留 `alpha、beta`，以便追溯点选或投影转换错误。每张图只需点击八个点，约 99 座候选桥适合采用人工点选、程序自动算比例的半自动标注方式；没有必要先训练图像关键点网络。

多跨桥采用“一跨一条节点标注”，每条记录关联 `bridge_id + span_index`。同一张全桥纵剖图可以重复作为各跨记录的来源图，但八点只框定当前跨；各跨按图纸从左到右编号。对设计几何，仍在每个单跨内部执行水平化、左右对称化和固定斜弦角预处理，不强迫边跨与中跨具有相同的 `alpha、beta`。同一桥各跨共享 `source_group_id`，训练/验证/测试划分不得跨组。

#### `dataset_manifest`

记录数据版本、来源快照、包含/排除的桥 ID、标注规范版本、代码提交、特征版本、划分版本和授权范围。

### 5.2 特征分层

生产模型只能使用系统在新设计时真实可得的参数。建议：

**核心生产特征**

- `clear_span_m`
- `rise_m`
- `width_m`
- `total_length_m`
- `n_three`, `n_five`
- `span_count`
- `rise_span_ratio = rise / clear_span`
- `width_span_ratio = width / clear_span`
- `length_span_ratio = total_length / clear_span`
- `left_slope_length / clear_span`、`middle_member_length / clear_span`（来自三节苗预测几何）

**仅用于研究和分层分析的字段**

- 地区、年代、桥名、网站 ID；
- 图纸分辨率、绘图者、数据采集方式；
- 维修史或变形状态。

这些字段若在新桥设计时不可得，不应进入最终生产模型；否则离线指标会好看但上线无法复现。

### 5.3 文本字段提取

网站结构化列表中的桥宽等字段不完整，不能仅依赖 API 固定字段。推荐流程：

1. 用规则和单位词典从详情说明中提取“桥长/宽/净跨/矢高”等候选值；
2. 保留原始句子、解析值和解析置信度；
3. 对所有训练样本人工复核，不让未经核验的 OCR/正则结果直接进入训练集；
4. 图纸尺寸线作为第二来源，若与说明冲突则进入专家裁决队列。

### 5.4 标注与质控

建议先标 10–15 座桥做试验，再决定是否扩展到全部候选桥。

- 试验集覆盖小/中/大跨径、不同年代、不同图纸清晰度；
- 至少 20%–30% 的桥由两位标注者独立标注；
- 以归一化跨度单位报告标注者间误差，并换算成实际厘米；
- 暂定：关键点分歧小于 `0.005 × 跨径` 可自动通过，`0.005–0.015` 进入复核，大于 `0.015` 重标或剔除；阈值应由试验集噪声调整；
- 同时报告 `alpha`、`beta` 的双人分歧，确认其明显小于样本间真实差异；
- 同一座桥的多张图可相互校核，但不得被拆到不同训练/测试集合；
- 数据表中明确记录“不可辨识”，禁止靠猜测补齐标签。

试验集完成后，先比较 `alpha、beta` 的样本方差与标注方差：若桥间变化与标注噪声处于同一量级，或与任何生产可用特征都没有稳定关系，应停止复杂建模，直接用数据校准后的中位数和置信区间替换当前假定值。这也是有效研究结论，不能为了使用机器学习而强行拟合噪声。

### 5.5 数据量决策门槛

| 最终有效桥梁数 | 建议策略 |
|---:|---|
| `< 40` | 以几何规则、专家标定和统计区间为主；机器学习只作探索，不宣称泛化 |
| `40–60` | Ridge/Huber、Gaussian Process、偏最小二乘等低自由度模型为主 |
| `60–100` | 可加入浅层 XGBoost，并使用严格嵌套交叉验证和残差约束 |
| `> 100` 且来源多样 | 再考虑更复杂的多任务模型；视觉网络仍需远多于百级的独立桥梁样本 |

应优先联系老师，确认原两阶段模型所用的 130+ 座桥数据中是否有对应立面图或节点记录。若能与网站数据去重后合并，研究价值和外部验证能力会明显提高。

## 6. 算法路线与取舍

### 6.1 必须保留的基线

论文和工程验收都必须包含当前固定规则：

- `alpha = 2/3`：外左、外右节点在斜杆上的比例；
- `beta = 1/4`：内左、内右节点在平杆上的比例；
- 四个坐标均由三节苗锚点和上述比例解析计算。

此外再加入两个不训练的基线：

- 全训练集标签中位数；
- 按矢跨比分箱后的中位数。

先对 `alpha、beta` 做分布、标注噪声和特征相关性检验。如果数据只支持一组稳定常数，就上线“校准常数 + 区间”，而不是机器学习模型；只有存在可复现的桥间变化时，才进入回归建模。如果复杂模型不能稳定超过这些基线，也不应上线。

### 6.2 候选模型

| 模型 | 优点 | 风险 | 定位 |
|---|---|---|---|
| Ridge / Elastic Net | 参数少、可解释、适合小样本 | 非线性能力有限 | 必做基线 |
| Huber 回归 | 对异常桥和轻度误标更稳健 | 同样偏线性 | 必做基线 |
| Gaussian Process | 小样本友好、天然给不确定性 | 特征多或样本增大后成本上升 | 推荐候选 |
| Random Forest | 鲁棒、实现简单 | 外推差、输出可能不连续 | 比较模型 |
| XGBoost | 可拟合非线性，和原论文技术路线衔接 | 小样本易过拟合，原生约束输出不方便 | 推荐主模型候选 |
| 端到端图像关键点网络 | 可直接读图 | 独立桥样本过少、图纸风格偏差大、解释弱 | 不作为第一阶段主线 |

视觉方法可以用于标注辅助，例如自动找图框、尺寸线或提出关键点候选，但第一篇论文不应把它作为核心预测器。

### 6.3 推荐主模型：知识约束残差学习

模型不直接从零预测四个节点，而只预测相对固定比例的两个修正量：

```text
y_rule = [2/3, 1/4]
delta  = f(features) = [delta_alpha, delta_beta]
y_raw  = y_rule + delta
[alpha, beta] = ProjectToFeasibleSet(y_raw)
Q1..Q4 = ReconstructFromThreeMiao(alpha, beta)
```

这样做的理由：

- 数据少时，模型默认接近已有设计经验；
- 学习目标的数值范围更小；
- 固定规则是清晰、可复现实验基线；
- 模型失败或越界时可自然回退；
- 便于解释每个输入让外侧/内侧比例相对旧规则改变了多少。

第一版建议分别实现：

1. Ridge 残差模型；
2. Gaussian Process 残差模型；
3. 浅层 XGBoost 残差模型。

用嵌套交叉验证选择最终模型，不能因为原论文采用 XGBoost 就预设它必然最好。

### 6.4 知识约束

约束应先由结构专家写成可测试规则，再写入模型后处理。至少包括：

- `0 < alpha < 1`，外侧节点不得越过拱脚或三节苗牛头；
- `0 < beta < 0.5`，两个内侧节点不得越过跨中或相互反序；
- `Q1、Q4` 必须由三节苗左右斜杆插值得到；
- `Q2、Q3` 必须由三节苗中间平杆插值得到；
- 四点必须按 `Q1-Q2-Q3-Q4` 排序并满足中心对称；
- 不得导致杆件交叉、零长度、负净距或明显不可构造的榫卯关系；
- 必须兼容原方案已有的数量关系和直径/净距约束。

对于树模型，建议把原始输出投影到可行域，而不是只在损失函数里加软惩罚。投影前后的距离也应作为质量指标：投影改动过大意味着输入可能越界或模型不可信。

### 6.5 不确定性与拒识

系统不应只返回四个看似精确的点。至少返回：

- `alpha、beta` 及四个恢复坐标；
- 两个比例的预测区间，以及换算后的四点误差范围；
- 是否超出训练数据分布；
- 是否触发约束投影；
- 使用了模型还是规则回退；
- 模型和数据版本。

小样本下可采用 Bootstrap 模型集成、Gaussian Process 区间，或在桥梁级交叉验证基础上使用 CV+ / conformal calibration。上线时设置两类拒识：

1. 输入特征超出训练范围或与最近训练样本距离过大；
2. 预测区间过宽、投影距离过大或约束仍无法满足。

拒识时返回旧规则位置，并在界面突出“需人工确认”，不要悄悄生成看似精确的节点。

## 7. 训练与验证方案

### 7.1 防止数据泄漏

- 所有划分至少以 `bridge_id` 为单位；存在原址/迁建、毁损/重建、多跨或共享测绘来源时，进一步按 `source_group_id` 分组；
- 同一座桥的照片、不同图纸和不同标注版本必须在同一折；
- 标准化、缺失值填充、特征选择和超参数搜索全部在训练折内完成；
- 锁定测试桥之后，不因测试结果调规则、删样本或改特征；
- 人工修正产生的新标签进入下一数据版本，不回填当前论文测试集。

### 7.2 建议验证方式

当有效样本不少于 60 时：

1. 按跨径和矢跨比分层，锁定约 15%–20% 的桥作为最终测试集；
2. 其余数据执行外层 5 折、内层 4 折的嵌套 GroupKFold；
3. 重复不同随机种子，报告均值、标准差和置信区间；
4. 最终只在方案完全冻结后评估一次锁定测试集。

当样本少于 60 时，不建议牺牲过多样本做单一测试集；改用重复嵌套交叉验证或 Leave-One-Bridge-Out，并明确说明证据等级。若能获得另一来源的历史桥数据，应把它作为真正的外部测试集。

### 7.3 指标

**主指标**

- `alpha`、`beta` 的 MAE / RMSE；
- 外侧节点物理误差 `|delta_alpha| × 斜杆长度`；
- 内侧节点物理误差 `|delta_beta| × 平杆长度`；
- 四个恢复节点中最大的位置误差（max-node error）。

**结构质量指标**

- 对称误差；
- 约束违反率；
- 投影前后距离；
- 杆件长度相对误差；
- 因节点误差导致的构件交叉或不可构造案例数。

**可信度指标**

- 90% / 95% 预测区间覆盖率；
- 区间平均宽度；
- OOD 样本的拒识召回率；
- 高置信样本覆盖比例。

由于四点坐标依赖上游三节苗预测，实验必须分两层报告：

1. **条件评估**：使用测绘图中的真实 `A、B、C、D`，只衡量 `alpha、beta` 模型误差；
2. **端到端评估**：使用系统预测的三节苗几何恢复四点，衡量上游几何误差与比例误差叠加后的最终结果。

上线时也应把三节苗预测的不确定性传播到四节点误差范围，避免把上游误差错误归因于节点模型。

最终应事先定义工程可接受误差，例如“节点误差不超过 X cm 或跨径的 Y%”。X、Y 需要由老师或结构设计人员依据榫卯和施工容差确定，不能由数据表现倒推。

### 7.4 消融实验

至少比较：

1. 固定 `alpha=2/3、beta=1/4` 规则；
2. 直接回归 vs. 规则残差回归；
3. 有无无量纲化；
4. 左右分别拟合 vs. 左右平均的中心对称目标；
5. 有无可行域投影；
6. 只用总体尺寸 vs. 加入数量特征；
7. 校准常数/分箱常数 vs. 可学习模型；
8. 使用全部现状桥 vs. 仅使用专家判定的设计适用桥。

## 8. 系统集成设计

### 8.1 模块边界

训练代码与在线推理解耦。建议新增：

```text
bridge_algorithm_service/
  node_geometry/
    schemas.py          # 输入输出结构
    features.py         # 特征计算与版本检查
    predictor.py        # 模型加载和推理
    constraints.py      # 可行域检查与投影
    fallback.py         # 当前固定规则
    registry.py         # 模型版本和元数据
  model_artifacts/
    five_miao_node/v1/
      model.*
      scaler.*
      feature_schema.json
      training_manifest.json
      metrics.json

ml_pipeline/
  acquire/
  annotate/
  prepare/
  train/
  evaluate/
```

在线容器只包含冻结后的推理产物；数据抓取、标注和训练不在 Web 请求中执行。

多跨设计第一版按“单跨预测、整桥组合”实现：`span` 表示单孔净跨，`spans_count` 表示孔数，节点模型对每个标准跨单元运行。等跨桥可直接组合；不等跨桥必须逐跨输入净跨并分别预测，不能用全桥平均跨长替代各跨。生成图纸应明确标注为“单孔标准拱架详图”，避免把一个单跨示意误解为整桥立面。后续若要输出包含桥墩和各跨差异的全桥立面，应另设跨数组输入与组合绘图模块，不改变本节点模型的跨内坐标定义。

### 8.2 API 兼容方案

可在现有 `/predict` 响应中增加 `geometry`，保留旧字段，避免一次性破坏前端：

```json
{
  "result": {
    "geometry": {
      "coordinate_system": "three-miao-segment-ratio-v1",
      "five_miao_bullhead": {
        "ratios": {"alpha_outer": 0.650, "beta_inner": 0.250},
        "points": {
          "outer_left":  {"u": 0.217, "v": 0.650},
          "inner_left":  {"u": 0.417, "v": 1.000},
          "inner_right": {"u": 0.583, "v": 1.000},
          "outer_right": {"u": 0.783, "v": 0.650}
        }
      },
      "uncertainty": {
        "alpha_interval": [0.625, 0.675],
        "beta_interval": [0.235, 0.265],
        "level": 0.90
      },
      "model_version": "five-miao-node-1.0.0",
      "feature_schema_version": "node-features-v1",
      "source": "ml",
      "ood": false,
      "projected": true,
      "needs_review": false
    }
  }
}
```

绘图函数不再自行猜测位置，而只消费 `geometry`：

- 有有效模型结果：从三节苗锚点和 `alpha、beta` 恢复 `Q1..Q4`，再转为画布坐标；
- 无模型或被拒识：使用 `2/3、1/4` 规则，并标记 `source = rule_fallback`；
- 用户手工修正：保存 `source = manual_override` 和修正前后值。

### 8.3 前端交互

建议在现有设计页增加：

- 显示 `alpha、beta`、四节点坐标及换算后的米制位置；
- 显示模型版本、置信区间、OOD/回退状态；
- 在图中用不同样式表示模型点、规则点和人工点；
- 支持拖拽节点，实时检查约束；
- 保存人工修正原因，如“节点识别错误”“结构经验修正”“特殊桥型”；
- 高风险状态下禁止把结果标为“已确认设计”。

人工修正是重要的数据闭环，但必须经过专家审核后才能进入下个训练版本。

### 8.4 版本和可复现性

每次预测结果至少留存：

- 输入参数原值；
- 特征 schema 版本；
- 模型版本和文件哈希；
- 训练数据 manifest 哈希；
- 预测前值、约束投影后值和回退原因；
- 推理时间和软件版本。

模型启动时应强制校验特征顺序和版本，不允许“列名相同但含义已变”的静默错误。

### 8.5 测试清单

**单元测试**

- 八点标注到 `alpha_L、alpha_R、beta_L、beta_R` 的投影计算；
- `alpha、beta` 到四节点坐标的解析重建；
- 中心对称和左右镜像；
- 边界、顺序、杆件归属和对称约束；
- 缺失值、非法尺寸和单位错误；
- 模型加载失败时的规则回退。

**模型测试**

- 固定验证样本的特征和预测快照；
- 指标不得低于登记阈值；
- OOD 输入必须被识别；
- 不同平台推理误差在容许范围内。

**接口与前端测试**

- 旧请求仍能得到原有字段；
- 新 `geometry` schema 可被前端解析；
- 绘图四个像素点与 `alpha、beta` 重建结果一致；
- 人工拖拽后约束提示正确；
- 模型缺失、损坏、超时和低置信度场景均有清晰提示。

## 9. 分阶段实施计划

### 阶段 0：问题定义与授权（第 1–2 周）

交付物：

- 四节点 `Q1..Q4`、三节苗锚点 `A..D` 和轴线取点标准；
- 中心对称设计假设，以及 `alpha、beta` 的计算规范；
- 现状值/设计值的标签政策；
- 数据使用和论文展示许可；
- 工程容许误差；
- 10–15 座试验桥清单。

退出条件：任取一张图，两位专业人员能一致指出目标点并按同一规则标注。

### 阶段 1：采集与数据清单（第 2–3 周）

交付物：

- 可恢复、限速、带缓存的接口采集器；
- API 和图纸 manifest；
- 候选桥筛选报告；
- 授权边界对应的数据存储策略。

退出条件：所有候选记录来源可追踪、文件哈希可复核、重复下载不会改变原始层。

### 阶段 2：标注试验（第 3–5 周）

交付物：

- 标注规范 v1；
- 10–15 座桥的双人标注；
- 标注者间误差和不可辨识原因统计；
- `alpha、beta` 的分布、左右对称误差、标注噪声与特征相关性报告。

**Go / No-Go 门槛**

- 若大多数图无法唯一辨识节点，先补充老师的数据或重新定义问题；
- 若双人分歧大于工程容差，不进入模型训练；
- 若 `alpha、beta` 的桥间变化不高于标注噪声，或没有可复现的特征关系，采用校准常数和区间，不训练复杂模型；
- 若最终预计少于 40 座有效桥，论文改为“测绘标注与知识规则校准”，不主打机器学习泛化。

### 阶段 3：完整数据集（第 5–8 周）

交付物：

- 经裁决的标注数据 v1；
- 数据说明卡、缺失值和质量统计；
- 冻结的训练/验证/测试桥 ID；
- 可复现的数据构建脚本。

退出条件：每条训练记录都能回溯到桥、图纸、标注者和原始像素坐标。

### 阶段 4：基线与模型（第 7–10 周）

交付物：

- 固定规则、中位数、线性模型、GP、RF/XGBoost 对比；
- 知识约束残差模型；
- 嵌套交叉验证、消融和误差分析；
- 模型卡和候选模型选择记录。

退出条件：候选模型在主要指标上稳定优于固定规则，同时不增加约束违反率；否则保留规则方案并分析为什么数据不足。

### 阶段 5：系统接入（第 10–12 周）

交付物：

- 版本化推理模块和 API；
- 绘图函数改用节点预测输出；
- 前端置信度、回退和人工修正交互；
- 单元、接口和端到端测试。

## 10. 小论文规划

### 10.1 推荐题目

暂定题目：

> 面向木拱桥参数化设计的五节苗牛头节点知识约束小样本预测方法

备选：

- 知识约束残差学习驱动的木拱桥五节苗节点位置预测；
- 数据—知识混合驱动的木拱桥关键节点几何补全方法；
- 面向智能设计的木拱桥五节苗牛头节点预测与不确定性评估。

题目中的“首次”“高精度”“通用”等表述，只有在完整文献检索和外部验证后才能使用。

### 10.2 论文问题陈述

可将问题写成：现有木拱桥智能设计方法能够预测总体参数和构件尺寸，但参数化生成还缺少五节苗四个牛头节点这一关键几何量；工程实现暂以 `2/3、1/4` 固定比例定位，尚无历史数据依据。由于三节苗几何已知，四点可压缩为两个受中心对称和杆件归属约束的无量纲比例。公开历史测绘资料规模小、标签隐藏在图纸中，并存在测量噪声，因此需要先验证比例的真实变异，再选择统计校准或知识约束小样本预测方法。

### 10.3 研究问题

- **RQ1：** 数据驱动模型能否在桥梁级严格验证下稳定优于固定比例规则？
- **RQ2：** `alpha、beta` 的桥间变化是否显著超过图纸标注噪声，并与可用设计参数形成稳定关系？
- **RQ3：** 残差学习、中心对称参数化和可行域约束各自贡献多少？
- **RQ4：** 不确定性与 OOD 拒识能否降低不可构造输出，并支持安全的人机协同？
- **RQ5：** 节点误差的降低能否改善下游杆件长度、交点关系和参数化图纸质量？

### 10.4 预期贡献

只有在实验支持后，论文可主张以下三类贡献：

1. 一个带来源追踪、双人质控和统一坐标系的木拱桥关键节点数据构建流程；
2. 一个面向小样本的知识约束残差预测方法，结合对称性、可行域和不确定性；
3. 一个接入智能设计系统的可复现实现，并通过下游几何和人机修正实验验证实用性。

如果原图不能公开，应将贡献表述为“数据构建流程和派生标签”，不能宣称发布完整开放图像数据集。

### 10.5 论文结构

1. **引言**：缺失节点几何为何阻塞参数化设计；固定比例规则的局限；本文问题和贡献。
2. **相关工作**：木拱桥参数预测、数据—知识混合设计、小样本结构回归、受约束几何预测与不确定性。
3. **数据集与问题定义**：来源、授权、标注、坐标系、质量控制和统计分布。
4. **方法**：规则基线、特征、残差模型、对称表示、可行域投影和拒识机制。
5. **实验设置**：桥梁级划分、基线、超参数、指标和工程容差。
6. **结果**：主结果、消融、误差分层、不确定性、OOD 和下游影响。
7. **系统应用**：API、参数化绘图、人工修正和案例。
8. **讨论与局限**：样本规模、地域偏差、现状/设计值差异、授权和外部验证。
9. **结论**。

## 11. 主要风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 节点定义不一致 | 标签无效，模型上限低 | 先做图示定义和双人试标 |
| 比例实际近似常数 | 复杂模型没有增益 | 先做方差/噪声检验；必要时把成果定位为数据校准而非 ML |
| 数据授权不清晰 | 无法批量使用或发表图纸 | 第 0 阶段取得书面许可，必要时仅发布派生坐标 |
| 有效样本不足 | XGBoost/神经网络过拟合 | 使用低自由度模型、残差学习和严格 CV；降低论文主张 |
| 网站字段缺失 | 特征不完整 | 文本提取 + 人工复核 + 图纸尺寸交叉校验 |
| 历史变形被当作设计规律 | 推荐节点偏离合理构造 | 区分 observed 与 reviewed_design，记录维修/变形 |
| 同桥多图泄漏 | 指标虚高 | 所有划分按 bridge_id 分组 |
| 模型外推 | 新桥生成不合理 | OOD 检测、预测区间、可行域投影和规则回退 |
| 只改善点误差、不改善设计 | 论文工程价值不足 | 增加杆件长度、拓扑约束和专家确认等下游指标 |
| 人工反馈污染测试集 | 后续结果不可比较 | 数据版本化，锁定测试桥永不进入训练反馈 |

## 15. 2026-08-14 实施状态补记

第 14 节记录的是规划阶段的仓库现状，当前实现已经推进到以下状态：

- 网站现有 103 份八点标注已完成预处理，102 条标准结构记录参与训练，1 条零平弦特殊构造按范围规则排除；
- v5 已修正桥级宏 MAE 调参口径，并冻结 81 条开发记录和 21 条独立内部留出记录；
- v6 在冻结开发集内比较 Ridge、Huber、ElasticNet、样条 Ridge、RBF-SVR、Gaussian Process 和浅层 Extra Trees，再用 Leave-One-Group-Out 确认候选；
- 替换门槛要求桥级宏 MAE 至少改善 `0.002`，且绝对误差 q90 不恶化超过 `0.005`。本轮没有复杂候选达到稳定替换条件，`alpha` 保留净跨 Ridge，`beta` 保留净跨+矢跨比 Ridge；
- 冻结独立内部留出桥级宏 MAE 分别为 `alpha=0.09333`、`beta=0.02991`，仍不可解释为外部验证；
- 已从用户原始备份恢复导师 SSA-XGBoost/CF-BPNN 两阶段数值链，转换为 XGBoost 原生模型和 CF-BPNN 数值权重包，并以哈希清单约束加载；
- 在线主链现为“SSA-XGBoost → CF-BPNN → v6 节点 Pilot → 确定性骨架几何”，前端显示 `alpha/beta`、模型版本和阶段来源；任一模型不可用时保留显式规则回退；
- v8 根据构造观察把外节点划分为前半区 `alpha<0.5` 和后半区 `alpha>=0.5`，采用 Logistic 前置门控与两套独立 Ridge。已知类型的开发集 LOGO MAE 降至 `0.05299`，但自动门控平衡准确率仅 `0.68834`，端到端 MAE `0.08457`，未通过相对 v6 的替换门槛，故只保留为论文实验与特征缺口证据；
- v9 不再新增人工重标或运行自动门控，历史类型按 `design_target_alpha=0.5` 派生，在线合同改为设计人员预先选择前/后半区。两类净跨 Ridge 的开发集 LOGO 桥级宏 MAE 为 `0.05296`、模式宏 MAE为 `0.05163`、q90 为 `0.10638`，相对 v6 明显改善，但相对分区中位数仅小幅改善，且边界敏感性分析未稳定通过 `0.002` 门槛；论文应定位为“设计模式先验下的条件预测”，不能声称自动结构识别或独立专家类型标签；
- 算法服务已具备 Pilot 模型开关、受信任产物加载、硬范围回退、局部样本稀疏提示、90% 经验误差区间和模型来源元数据；v9 受控启用时只覆盖 alpha，beta 继续使用 v6，失败时回退 v6。

22 条高误差样本已经逐图复核，点位和原图匹配均无问题，因此不再把残差直接解释为标注错误。地形、墩台沉降、施工尺寸、腐蚀和测量误差是总体可能机制，但没有逐桥证据时不做具体成因标签。v7 已把目标拆为原始历史观测、历史左右均值代理和专家规范设计目标三层；当前 103 条记录中 102 条可用于历史代理研究，专家规范目标批准数为 0。

v7 在冻结 v5 分区上进一步比较 Ridge、Huber 和中位数分位回归。稳健候选在开发集中的微小差异没有达到预设的 `0.002` 桥级宏 MAE 替换门槛，`alpha` 和 `beta` 继续保留 Ridge，冻结留出桥级宏 MAE仍为 `0.09333` 和 `0.02991`。该结果说明仅更换损失函数不足以分离桥型差异与服役扰动；下一轮应优先补录专家规范目标与设计时可取得的结构特征，而不是删除真实历史样本或继续无约束堆叠模型复杂度。
