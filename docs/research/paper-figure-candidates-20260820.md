# 五节苗节点预测论文图片备选说明

> 整理日期：2026-08-20。PNG 用于快速预览和导师汇报，PDF 为论文排版矢量版本。

## 正文优先图

1. `01_alpha分区专家测试集效果`：论文核心结果。展示设计人员给定前/后半区时，v9 条件双专家相对固定规则、v6 单模型和分区中位数的表现。
2. `02_beta平弦节点测试集效果`：展示 beta 模型在独立内部留出上的预测、误差和物理位置误差。
3. `03原始标签与完整预处理严格对照`：新增严格配对实验。开发集 alpha 桥级宏 MAE 降低 4.1%，内部留出降低 3.3%；beta 数值等价。
4. `04平行角度修正物理诊断`：解释为什么 alpha 必须做平行角度修正；普通投影会把构件厚度和起点抬高混入标签。
5. `05完整流程与逐项预处理消融`：展示完整流程相对固定规则、训练中位数的总体优势，以及逐项关闭预处理的敏感性。

## 补充材料备选

6. `06预处理贡献与物理误差`：左右对称、净跨补全、分组防泄漏和节点物理误差四联图。
7. `07严格对照逐样本诊断`：展示平行角度修正对 alpha 预测的系统移动，以及内部留出逐样本收益/损失并存的事实。
8. `08完整流程OOF预测与误差分布`：展示 102 条标准样本的 OOF 拟合形态和绝对误差分布。
9. `09测试集残差与物理误差分布`：展示 alpha/beta 测试误差分布及随净跨变化的物理误差。

## 推荐讲述顺序

导师汇报建议按 `04 → 03 → 05 → 01 → 02 → 09`：先说明标签为什么需要修正，再给严格对照和消融，最后展示模型在冻结内部留出上的实际效果。

## 论文口径限制

- 严格对照说明 alpha 有小幅一致改善，但开发集和内部留出的配对 bootstrap 95% 区间均跨 0，不能写“显著提升”。
- 严格对照的共同评估目标是预处理得到的对称设计代理，不是独立专家真值；它主要验证标签构造一致性，不能单独证明恢复了古桥的原始设计意图。
- beta 的对称预处理在当前线性模型中与左右分别建模后取均值数值等价；beta 的主要改进来自建模、样本范围控制和元数据补全，不来自均值运算本身。
- 所谓“独立留出”仍来自同一网站数据源，不是外部测试集。
- v9 的前/后半区由设计人员给定；不得把结果表述为系统自动识别结构类型。
- 图片中的 alpha、beta 是无量纲节点比例，物理位置误差才以米为单位。
