# 五节苗牛头节点数据集：来源与采集约束核查

**核查日期：** 2026-08-11（Asia/Shanghai）  
**范围：** 历史桥梁数据库 `w-bridge.wiki` 的公开数据面，以及论文《数据-知识混合驱动的木拱桥设计参数两阶段预测模型》的出版方全文。本文只记录已核实的一手证据、可复现采集路径与风险；不代表已取得批量下载、模型训练或再发布授权。

## 1. 结论摘要

1. 网站前端公开读取四类静态 JSON：桥梁列表、桥梁详情、标签和分类；图片与测绘图由独立静态 CDN 提供。当前列表一次返回 250 条记录，网页中的每页 15 条是浏览器端分页，不存在已发现的服务端分页接口。
2. 当前快照中，分类 ID `18` 对应“木拱”，共有 132 条；其中以 `keyword` 匹配 `3+5` 可得到 112 条候选，99 条同时带“有测绘图”标签（ID `59`）。这是候选筛选启发式，不是网站提供的“五节苗”规范字段或节点标签。
3. API 没有牛头节点坐标、构件端点、矢高、桥宽或比例尺等结构化几何字段。详情中的 `drawings` 只是 JPEG 图纸的元数据与相对 URL。牛头节点监督标签必须在获得授权后，从纵剖面/拱架图中人工或半自动标注，并用实桥尺寸复核。
4. 网站“关于”页声明内容和图像版权归原作者；不超过 10 张照片或图纸时按 CC BY-NC-ND 4.0、署名且限非商业使用，超过该数量或商业使用需联系授权，正式学术出版还要求提前通知原作者。拟使用约 99 组测绘图建立训练集显然超过 10 张；裁切、标点、派生标签和公开数据集还可能涉及“禁止演绎”的边界，因此批量抓取和训练前必须取得书面许可。
5. 已确认论文正式题名为《数据-知识混合驱动的木拱桥设计参数两阶段预测模型》。论文方法是“SSA-XGBoost 预测矢跨比 + 专家知识增强 CF-BPNN 预测节苗根径范围”，并未预测牛头节点位置。其数据-知识混合思路可以借鉴，但不能直接复用为节点定位模型。
6. 论文使用 130 余座桥、80:20 训练/测试划分，却以测试集 MAE 作为超参数优化目标且未设验证集；这会产生测试信息泄漏风险。新研究必须使用桥梁级分组验证、独立测试集或嵌套交叉验证。

### 3.4 惠风桥（ID 79）实测结果

S6 中的关键结构化值为：名称“惠风桥”，结构“木拱”，单跨，长度 `30.010 m`，最大跨径 `22.950 m`，关键词 `3+5`；详情含 6 张照片和 5 张测绘图。图纸包括纵剖面、横剖面、拱架俯视、平面和北立面，作者字段具体到课题组/绘图者，说明字段称其来源为三维扫描与手工测绘。

代表性纵剖面图的第一方静态 URL：

<https://aujrht7gmph6dk84wqh975zv.z7.web.core.windows.net/static/157493261852073/draw/1722342623742.%E7%A6%8F%E5%BB%BA%E7%9C%81%E5%B1%8F%E5%8D%97%E5%8E%BF%E6%83%A0%E9%A3%8E%E6%A1%A5-%E7%BA%B5%E5%89%96.jpg>

结构化 JSON 中没有以下目标信息：

- 四个五节苗牛头节点的像素或实际坐标；

## 6. 获权后的可复现采集路线

1. **固定授权和快照。** 保存授权邮件、许可范围、抓取时间、S4 脚本哈希、S5/S7/S8 的 ETag、Last-Modified 与 SHA-256。
2. **一次获取索引。** 条件 GET S5/S7/S8；不要伪造分页。按“木拱分类 + `3+5` 关键词”生成候选清单，并保留所有排除原因。
3. **低速获取详情。** 仅请求候选 ID 的 `/bridge/{id}/detail`，单并发、建议不高于 1 请求/秒，使用缓存、条件请求、指数退避；这是自愿保护措施，不是网站公布的额度。
4. **只下载获权资产。** 拼接 `cdnHost + drawings[].url`；校验状态码、文件签名、长度、ETag 和 SHA-256，并原样保存作者、日期、题名、说明和详情页 URL。
5. **建立桥梁级溯源。** `bridge_id` 不是独立样本的充分条件；原址/迁建、毁损/重建、多跨和同一测绘图的派生版本应共享 `source_group_id`。
6. **标注几何而非只标像素。** 根据项目负责人 2026-08-11 提供的示意图，目标为外左、内左、内右、外右四个五节苗牛头节点。第一版忽略厚度并按中心对称设计，应同时标注四个三节苗锚点和四个目标点，计算外侧斜杆比例 `alpha` 与内侧平杆比例 `beta`；至少双人独立标注加仲裁。
7. **保留不可用样本。** 图纸无比例、节点遮挡、来源冲突或非标准构造时标记原因，不用主观补点。模型的数据划分按桥梁/谱系分组，不按图片随机划分。
8. **遵守停止条件。** 遇到 403/429、许可变化、站方要求停止或资产权属不清时立即暂停，不绕过访问控制。

### 7.2 数据—知识混合方法

| 环节 | 论文做法 | 与节点预测的关系 |
|---|---|---|
| 数据来源 | 整合既有结构调查、刘妍数据库与实地调研，称覆盖闽浙 130 余座木拱桥；测量并经专家验证 | 证明“小样本实桥数据 + 专家约束”的路线可行，但不能证明当前网站 132 条木拱记录就是论文原训练表 |
| 第一阶段 | 输入长度、宽度、跨度，以 SSA 优化 XGBoost 的树深、树数量、学习率和子样本比例，预测矢跨比 | 可作为节点模型的全局几何先验；不输出节点 |
| 第二阶段 | 将设计参数和预测矢跨比送入专家知识增强的级联前向 BP 网络，执行多输入多输出回归 | 可借鉴为“几何特征 + 规则惩罚”的节点坐标回归框架 |
| 网络 | 报告 7 维输入、10 维输出、`7-16-10-10` 拓扑、ReLU、100 次迭代 | 论文没有给出可直接替换为 4 个节点坐标输出的代码 |
| 专家知识 | 损失为数据误差加惩罚项；约束 `D3*n3 + D5*n5 < d + δ` 且 `n3 = n5 + 1` | 约束针对节苗直径/根数和桥宽，不是牛头节点几何约束 |
| 目标 | 先预测矢跨比，再预测三节苗、五节苗各类木材根径范围 | 不包含牛头节点位置，必须重新定义标签和知识约束 |

论文数据表给出长度、宽度、跨度、矢高、矢跨比、两系统拱肋数及五类节苗根径等参数，并在建模前归一化。矢跨比模型比较 RF、BPNN、AdaBoost、XGBoost 与 SSA-XGBoost；报告后者测试集 `MAE=0.018`、`RMSE=0.033`、`R²=0.980`。根径模型比较 RF、BPNN、MO-SVM、RBF-NN 与本文 CF-BPNN；报告本文模型 `MSE=0.0075`、`MAPE=4.88%`、`RSS=1.42`，两个工程案例中的最大误差为 8.2%。这些数值只适用于论文任务与其未公开划分，不能作为牛头节点模型的预期指标。

### 7.3 方法学风险与复现缺口

- 论文按 80:20 划分训练/测试集，没有独立验证集；同时明确以最小化测试集 MAE 优化超参数，再报告测试指标。新研究若照搬会产生乐观偏差。
- “130 余座”不是精确样本数；逐桥样本、缺失值处理、随机种子、分层/分组规则和模型代码均未公开。
- 论文称第二阶段为 7 维输入，但正文和参数表没有完全无歧义地映射这 7 个输入字段。
- 当前网站数据会更新，且论文引用的是 2025-01-26 访问的旧版数据库；当前 2026-08-11 快照与论文训练数据的重合度未知。
- 四个牛头节点存在左右对称、图纸方向、构件轴线取点和非标准构造差异；在形成八点标注与 `alpha、beta` 计算规范前，不应先训练图像或回归模型。

## 8. 决策门槛

可进入正式数据集建设的最低条件是：

1. 权利人书面允许超过 10 张图纸的下载、标注、训练和约定范围的论文使用；
2. 结构专家书面定义四个牛头节点、四个三节苗锚点以及 `alpha、beta` 的计算口径；
3. 先对不超过授权范围的小样本进行可标注性试验，确认纵剖面图能稳定定位节点；
4. 建立桥梁级去重/分组和独立测试协议；
5. 明确原图、派生标签、模型权重分别能否保存、共享和发表。

在上述条件满足前，网站适合用于估算样本规模和制定标注方案，不适合直接作为已获许可的训练数据源。
